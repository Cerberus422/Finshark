# FinShark API

FinShark is a stock market REST API built with ASP.NET Core and Entity Framework Core.

This project was created as a learning project to practice building a backend application with .NET, working with databases, authentication, relationships, DTOs, repositories, and RESTful APIs.

## Features

- User registration and authentication
- JWT authentication
- Stock CRUD operations
- Stock comments
- User-specific comments
- Comment creation, updating, and deletion
- User portfolios
- Many-to-many relationship between users and stocks
- Entity Framework Core
- SQL Server database
- Repository pattern
- DTOs and mapping
- Swagger / OpenAPI documentation

## Technologies

- C#
- ASP.NET Core Web API
- .NET 10
- Entity Framework Core
- SQL Server
- ASP.NET Core Identity
- JWT Authentication
- Swagger / OpenAPI
- Git / GitHub
